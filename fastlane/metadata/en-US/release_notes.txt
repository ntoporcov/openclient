Stay in the loop with OC Notify.

• Set up optional Web Push notifications for completed sessions, permission requests, and questions using OC Notify on your own host.
• Follow the guided setup to add the companion web app to your Home Screen and transfer your connection settings from OpenClient.
• Open notifications to return to the relevant session in OpenClient.
• Enjoy more reliable OpenCode v2 connections, with fixes across projects, workspaces, sessions, tools, and live updates.
• Reach Connection Settings directly from project and Activity settings, alongside Global Settings.

OC Notify requires the OpenClient plugin, a self-hosted HTTPS endpoint, and the companion web app added to your Home Screen. Notification delivery uses Web Push without an OpenClient-hosted relay.
